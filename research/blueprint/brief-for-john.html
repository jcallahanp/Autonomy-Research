Sheet 1 of 3How a project flows

What the engineer is

The engineer is a packaged Claude Code setup that takes a project from your spoken brief to deployed, checked software, with you only designing and approving. It runs on one Ubuntu server (a rented machine) you control. Once you approve a plan, a supervisor (a small control program) works through small tasks overnight, one fresh Claude Code run per task, each capped in turns, money and time. Scripts decide when a task is done, never the model's own claim, and two failed tries park a task instead of looping.

  3. An existing system is mapped read-only, and you sign off the map.

  5. It writes the plan and a three-page brief like this one. Your approval is locked to that exact version.
  6. Overnight: build, automatic checks, a script audit, one pull request (proposed change) per task.
  7. A big change of course (goal, scope, cost) comes back to you; other tasks carry on.
  8. Every night ends in a known state, with a morning report and one Telegram list.

Where every key lives

  • Service keys, main tokens and the approvals bot: an encrypted file that only a separate key-holding account (the broker) can read. The engineer never sees a value.
  • Trial test keys: added on the wire by a network gatekeeper (proxy).
  • Cloud deploy keys: none stored; short-lived tokens per job.
  • Browser logins: the Chrome profile, readable by the engineer's account.
  • Your Max login: Claude Code's own store. Whether the model can read it is unchecked.
  • An API key, if you choose one: the encrypted file, passed only into task runs and treated as exposed, so every run has a spend cap.
  • Production, billing and backups: only you.

What you will see day to day

  • Morning report: what finished, what is blocked and why.
  • Daily Telegram list at 07:30: numbered lines with recommended defaults. Reply "all y" or "1 y 2 n"; unclear replies never approve. Reversible items take their default after 24 hours (untested).
  • Instant hard-gate prompts: spending money, deleting data, app-store submission. These need a typed confirmation and never default to yes.

  • May anything outside Anthropic see health data?No.
  • Where does n8n run, and may it write to Outreach?n8n stays where it is; no Outreach writes.

Your one setup sitting

After a short bring-up (rent the server, run one install script, log in to Claude), one block with the long waits first:

  1. Start the slow approvals: Outreach app (needs your employer's OK), Google sign-in app, WHOOP and Withings developer apps.
  2. Sign up for healthchecks.io and UptimeRobot.
  3. Make a GitHub bot account, its token and branch protection.
  4. Merge the builder's template pull request.
  5. Two Telegram bots, and the Remote Control phone view.
  6. Cloudflare account and one main token.
  7. Attio and n8n keys, Clay sign-in, Google Cloud roles, Slack token.
  8. Log in to Google, Attio, Clay, n8n and Outreach in the server's browser and click every consent screen.
  9. Privacy toggle, confirm the hard gates, run the lock command.

Time: 45 to 90 minutes is an unsourced guess, to be timed.

Unproven, to test first

  1. Whether unattended Claude Code on your Max login fits Anthropic's terms.
  2. What each login choice loses: phone view, connectors, page publishing.
  3. Whether the turn, money and time caps stop runs cleanly.
  4. Whether the "done" checks block a false "done" with nobody watching.
  5. Whether the sandbox resists bypass tricks, and a planted fake secret never reaches the logs.
  6. Whether it pauses at a usage limit and resumes alone.
  7. Whether each sign-in consent lands its token for Google, Outreach, WHOOP, Withings and Slack.

How strong is this?

The evidence is mostly vendor docs and benchmarks. Nothing has been run or installed, and many settings (caps, timeouts, server size, allowed websites) are untested defaults. A fresh check of 20 citations found none wrong, but only 14 fully supported against a bar of 17, because some summaries added detail beyond their sources. Those were corrected.

What building it starts with
