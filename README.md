# Autonomy Research

Research toolkit and findings for building a fully autonomous Claude Code engineer. The current
phase designs and builds the **project-development research agent** that will do that research.

- `docs/proposal/` — the research-agent proposal awaiting sign-off
- `docs/diagrams/` — small Mermaid architecture diagrams, one concern each (see `index.md`)
- `research/findings/` — cited research behind the proposal (architecture, context management,
  tool routing, methodology, packaging), in the shape of `_FORMAT.md`
- `research/tool-registry.md` — every tool evaluated, with a verdict
- `research/open-questions.md` — what the evidence could not settle
- `CLAUDE.md` — research conventions Claude follows in this repo
- `.mcp.json` — project MCP servers (DeepWiki, Playwright)
- `scripts/cloud-setup.sh` — installs Superpowers in cloud sessions
- `scripts/playwright-mcp.sh` — starts Playwright with the right browser in cloud sessions
